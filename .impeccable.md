## Design Context

### Users
**Who**: Women in tech applying to jobs in Mexico, frustrated by systemic pay gaps and uncertain about salary negotiation.

**Context**: Users arrive anxious and hopeful — they need concrete data to feel confident negotiating. They're often analyzing job postings during limited free time, possibly after work. The tool must reduce cognitive load, not add to it.

**Job to be done**: Get instant, actionable intelligence on job fit + salary data to feel empowered walking into interviews/negotiations.

**Emotional state**: Frustrated by inequality, hopeful for change, needs confidence boost.

### Brand Personality
**3 words**: Trustworthy, feminist, empowering

**Voice**: Professional but warm. Data-driven without being cold. Speaks directly to women's experiences in tech without being preachy.

**Emotional goals**:
- Reduce anxiety around salary negotiation
- Build confidence through concrete data
- Validate frustration (pay gap is real) while providing agency

### Positronica Labs Design System — "The Clinical Sublime"

FairHire now uses the Positronica Labs design system. The aesthetic is luminous, clinical, and weightless — like a high-end holographic research instrument, not a consumer social app.

#### Color Palette
| Token | Hex | Usage |
|---|---|---|
| **Lavender (Primary)** | `#C4B5E3` | Key actions, labels, glows, ghost borders |
| **Lavender Dim** | `#554971` | Section labels, subdued text |
| **Lavender Fixed** | `#d7c7f6` | Gradient stops, lighter surfaces |
| **Pink (Biological)** | `#E8A0BF` | Pay gap alerts, warnings, particles |
| **Pink Soft** | `#ffcfec` | CTA gradient end, soft highlights |
| **Green (Synthetic)** | `#98FF98` | Positive indicators, high fit scores |
| **Gold (Quantum)** | `#FFD700` | Data viz highlights |
| **Surface** | `#F6F6F6` | Base background |
| **Surface Container Lowest** | `#FFFFFF` | Glass cards (at 70% opacity) |

#### Typography
| Font | Usage |
|---|---|
| **Orbitron** | Brand name, section labels, data points, scores, technical specs |
| **Space Grotesk** | Headlines, page titles, section headers |
| **Inter** | Body copy, descriptions, labels, form text |

**Rules:**
- Never use Orbitron for body copy — it's a structural element only
- Orbitron always uppercase with wide tracking (0.15em–0.2em) for labels
- Space Grotesk for headlines: 36px–60px, bold, tight tracking

#### Surface Hierarchy
- **Base:** `#F6F6F6` with dot grid pattern (`radial-gradient` lavender dots at 8% opacity, 40px spacing)
- **Cards:** Glassmorphism — white at 70% opacity, `backdrop-blur(16px)`, 1px lavender border at 15% opacity, 24px radius
- **Elevated:** Increase blur to 32px + opacity to 85% (lens focusing effect, not Y-axis lift)

#### The "No-Line" Rule
**No standard 1px solid borders for sectioning.** Structural boundaries use:
1. **Tonal shifts** between surface tiers
2. **Ghost borders** — lavender at 15% opacity
3. **Animated gradient dividers** — lavender → pink → lavender, 1px, animated

#### Buttons
- **Primary:** Lavender gradient (`#C4B5E3` → `#d7c7f6`), dark text, 2px radius
- **Ghost:** No background, 1px lavender border, lavender text
- **Hover:** 4px lift + lavender glow (`box-shadow: 0 0 20px rgba(196,181,227,0.4)`)

#### Depth Model
**No traditional drop shadows.** Use:
- **Tonal layering** — surface container tiers for natural lift
- **Ambient glow** — lavender at 20-25% opacity, 20-24px blur for hover/active
- **Z-axis hover** — translateY(-4px) + glow (only for primary buttons)
- **Lens focus** — increase blur 16px → 32px on card hover (preferred)

#### Border Radius
- **2px** (sm) — buttons, badges, inputs
- **24px** (full) — glass cards only
- Never use heavy rounding — this is a high-tech lab, not a consumer social

### Accessibility
- **Target**: WCAG AA compliance
- **Color contrast**: Ensure all text meets 4.5:1 minimum
- **Color blindness**: Don't rely solely on color — use icons, labels, patterns
- **Motion**: Respect reduced-motion preferences for animations
- **Orbitron numbers**: Always paired with descriptive labels for screen readers
